🎯 About the Project
GameNest is an interactive web project that brings several games together in one website.

The main purpose of this project is to demonstrate how JavaScript can make a webpage dynamic, interactive, and functional.

Users can visit the main page, choose a game, play it directly in the browser, and return to the main GameNest page.

The project was developed as a final JavaScript group project.

🧠 JavaScript Concepts
This project was created to demonstrate the JavaScript concepts learned during the course.

✅ Conditions
We use:

if
else if
else

to make decisions during gameplay.

🔁 Loops
Loops are used when repeated operations are required.

⚙️ Functions
Functions organize reusable game logic and make the code easier to maintain.

📦 Arrays
Arrays are used to store collections of game data and choices.

Example:

let choices = ["rock", "paper", "scissors"];


🌐 DOM Manipulation
JavaScript dynamically selects and updates HTML elements.

Example:

document.getElementById()

🖱️ Events
User interactions are handled using JavaScript events.

Example:

addEventListener()

📝 Form Validation
User input can be checked before it is processed.

🎲 Random Numbers
Random numbers are used in games such as Rock Paper Scissors and Pig Game.
