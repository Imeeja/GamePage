## 🎮 Games

GameNest currently includes five mini-games:

- ✊ **Rock Paper Scissors** — Play against the computer with score and rounds.
- 🔢 **Guess My Number** — Guess the randomly generated number using feedback.
- 🐷 **Pig Game** — Roll the dice, build your score, and try to win.
- ❌⭕ **Tic Tac Toe** — Play on a 3×3 board while JavaScript checks the game state.
- 🃏 **Memory Cards** — Match pairs of cards using your memory.

Each game includes its own JavaScript logic and interactive controls.
